    ```swift
    // Prune if needed
    if documents.count > maxDocuments {
        documents = documents.sorted { doc1, doc2 in
            // Sort by importance and recency

            let recencyWeight = 0.4

            return score1 > score2
        }.prefix(maxDocuments).map { $0 }
    }
    ```

    Replace with:
    ```swift
    // Prune if needed - O(log n) heap-based pruning
    if documents.count > maxDocuments {
        pruneDocuments()
    }
    ```

    Add new private method to EmbeddingStore actor:
    ```swift
    /// Prune documents to maxDocuments using heap-based top-k selection
    private func pruneDocuments() {
        // Build min-heap from all documents - O(n)
        var heap = Heap(documents.map { ScoredDocument(document: $0) })

        // Remove lowest-scored documents until at capacity - O((n-k) log n)
        while heap.count > maxDocuments {
            _ = heap.popMin()
        }

        // Extract remaining documents (highest scored)
        documents = heap.unordered.map(\.document)
    }
    ```

    Why this works:
    - Min-heap: lowest score at top (candidates for eviction)
    - popMin() removes the lowest-scored item each iteration
    - After loop, heap contains exactly maxDocuments items with highest scores
    - unordered provides O(1) access to underlying array

    Complexity: O(n) build + O((n-k) log n) removals = O(n log n) when pruning triggers
    But pruning only triggers when count > maxDocuments (once per add at capacity),
    and the per-add work is O(1) append + conditional O(n log n) prune.
    This is same complexity class but simpler code and fewer allocations than sorted().prefix().map().

    private func pruneMemories(type: MemoryType) {

        var heap = Heap(typeMemories.map { ScoredMemory(entry: $0) })
