  <action>
Update `set(_ key:response:query:metadata:)` method:
- Before inserting entry, check if `cache[key] == nil` (new entry)
- If new entry: increment `counters.totalEntries` by 1 and increment `counters.ageBuckets["< 1h"]` by 1 (new entries start in freshest bucket)
- If replacing existing entry: no counter changes needed (entry count unchanged)

Update `get(_ key:query:)` method - exact match path (Level 1):
- On successful hit (not expired): increment `counters.totalHits` and `counters.exactHits`
- On expired entry removal: increment `counters.missReasons["expired"]`, decrement `counters.totalEntries`

Update `get(_ key:query:)` method - semantic match path (Level 2):
- When `findSimilarMatch(query:)` returns a result: increment `counters.totalHits` and `counters.semanticHits`
- Note: Move miss reason tracking to after both paths fail

Update `get(_ key:query:)` method - miss tracking (after both paths fail):
- If `cache.isEmpty`: increment `counters.missReasons["empty_cache"]`
- Else if `query == nil`: increment `counters.missReasons["no_embedding"]`
- Else: increment `counters.missReasons["no_match"]`

Update `findSimilarMatch(query:)` method:
- Remove any existing miss reason tracking from this method (it will be handled in `get()` after the call returns nil)
- Note: The method should only return the result or nil; tracking happens at the get() level to avoid double-counting

Update `invalidate(_ key:)` method:
- If `cache.removeValue(forKey: key)` returns non-nil: decrement `counters.totalEntries`

Update `pruneCache()` method:
- Calculate entries removed: `let removed = before - cache.count` (where `before` is count before pruning)
- Decrement `counters.totalEntries` by `removed`
- Note: Age bucket decrements are handled by lazy recalculation; don't track per-entry buckets

Update `clear()` method:
- Reset `counters = CacheCounters()` to reinitialize all counters

Remove the old O(n) iteration code that was calculating totalHits and ageDistribution inline.

- Call `recalculateAgeBuckets()` to populate age buckets
- Set `counters.lastRecalculated = Date()`
